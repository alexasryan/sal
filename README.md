# Сайт-визитка адвоката

Современный одностраничный сайт для юридической практики с акцентом на доверие и профессионализм.

## Технологии
- React 18 + TypeScript
- Tailwind CSS
- Framer Motion
- React Hook Form + Zod
- Lucide React

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Структура проекта

```
src/
├── components/
│   ├── ui/          # Переиспользуемые UI-компоненты
│   ├── sections/    # Секции главной страницы
│   └── layout/      # Компоненты макета
├── hooks/           # Кастомные хуки
├── utils/           # Утилиты и валидация
├── constants/       # Константы (данные сайта)
└── types/           # TypeScript типы
```

## Дизайн-система

- **Цвета**: Deep Navy (#0F172A) + Gold (#C5A065) + White
- **Шрифты**: Playfair Display (заголовки) + Inter (текст)
- **Принципы**: Минимализм, воздух, строгая сетка, доступность

## Особенности

- Mobile-first адаптивность
- Плавные анимации (Framer Motion)
- Валидация форм с Zod
- Доступность (a11y)
- Оптимизированная производительность
