# Активация формы и оплаты

Настройки находятся в `site.config.json`. Секретные ключи клиенту не нужны.

## Обращения

1. В своем аккаунте Formspree создайте форму, подтвердите адрес получения и скопируйте публичный URL `https://formspree.io/f/…`.
2. Настройте разрешенный домен `alexasryan.github.io`, spam filtering, лимиты и требования хранения/места обработки. CAPTCHA требует отдельной реализации и обновления политики.
3. Запишите URL в `form.endpoint`. Отключите `demo` после замены данных и проверки правовых текстов.
4. Пересоберите, опубликуйте, отправьте безопасный тест и подтвердите доставку в кабинете и почте.

JSON POST: `name`, `email`, `phone`, `service`, `message`, `preferred`, `consent`, `_subject`, `_gotcha`, `submissionId`, `privacyVersion`. Заголовки: `Content-Type: application/json`, `Accept: application/json`. Cookies и referrer не передаются. Успехом считается только HTTP 2xx. Заполненный honeypot блокирует запрос до сети. Submit блокируется на время запроса; после успеха идентичный payload блокируется в памяти текущей вкладки. Таймаут — 15 секунд, автоматических повторов нет.

Можно использовать собственный HTTPS serverless endpoint с тем же контрактом. Сервер должен валидировать поля, проверять origin/согласие, ограничивать размер и частоту, обрабатывать CORS для точного origin, хранить секреты только на сервере, обеспечивать дедупликацию и возвращать 2xx только после приема. Не журналируйте описание юридической ситуации без необходимости.

Документация: https://help.formspree.io/articles/building-your-form/submit-forms-with-javascript-ajax/

## Stripe Payment Link

1. Нужен подтвержденный merchant account Stripe, подходящий вашей компании и юрисдикции. Создайте разовую услугу, цену, валюту и налоговые параметры.
2. Укажите действующие реквизиты продавца, контакт поддержки, правила отмены/переноса/возврата, чек и подтверждение оплаты.
3. Скопируйте live Payment Link `https://buy.stripe.com/…` в `consultation.paymentUrl`. Синхронизируйте `price`, `currency`, `minutes`. Код отклоняет поддельные домены, HTTP и `/test_` в production.
4. При необходимости настройте возврат на `https://alexasryan.github.io/sal/payment-return/`. Страница не подтверждает платеж: проверка выполняется в Stripe или через webhook с проверенной подписью на сервере.
5. Время консультации согласовывается отдельно. Payment Link не подключен к календарю и сам по себе не резервирует слот.

Документация: https://docs.stripe.com/payment-links

**От владельца нужны:** публичный endpoint созданной формы, live Stripe Payment Link, реальные реквизиты и согласованные условия услуги. Пароли, токены и secret keys передавать не нужно. До активации сайт остается демонстрацией.
